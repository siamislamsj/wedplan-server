# WedPlan | Wedding Planning Platform

## About the Project

WedPlan is a modern wedding planning platform that connects couples with professional wedding service providers. It simplifies service discovery, wedding bookings, payments, and vendor management through a seamless digital experience.

## Technologies Used

**Frontend**
- Next.js
- React.js
- JavaScript
- Tailwind CSS
- ShadCN UI
- Framer Motion

**Backend**
- Node.js
- Express.js
- MongoDB Atlas
- Better Auth
- JWT Authentication

**Integrations**
- Stripe Payment Gateway
- Google Authentication
- ImgBB Image Hosting
- Vercel Deployment

## Key Features

- Role-based Customer, Vendor, and Admin dashboards
- Wedding service discovery with advanced search and filtering
- Service booking and request management
- Secure authentication and authorization
- Vendor service management and approval system
- Free and Premium vendor subscription plans
- Stripe payment integration
- Responsive and modern wedding-themed interface

## Unique Features

- Dynamic Special Offers and discounted pricing
- Dual currency price display in BDT and USD
- Wedding decoration inspiration gallery
- Customer payment history and downloadable receipts
- Centralized admin booking and transaction monitoring
- Premium vendor membership system
- Smooth animations and interactive service cards
